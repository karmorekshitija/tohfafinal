## Unlock Protocol

To intentionally make a change to a locked zone:

### For AI edits:
Include this phrase in your message:
```
Tohfa-LOCK-OPEN-2024
```

### For GitHub/code changes:
1. Go to `github.com/karmorekshitija/tohfafinal` → Settings → Branches
2. Find `stable/buyer-admin` rule → Uncheck "Lock branch"
3. Make your change
4. Re-enable "Lock branch" after merging
5. Update this manifest with the new commit SHA

### After any intentional change:
- Update the **Git Commit** row in this file
- Note what changed in **Known Working State**
- Re-lock the branch
