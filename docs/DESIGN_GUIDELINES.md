# TOHFA — DESIGN_GUIDELINES.md

## Mandatory rule
READ THIS FILE AND `SCOPE.md` BEFORE EVERY FRONTEND TASK.

## Brand character
Tohfa = premium Indian customised gifting.

Visual personality:
- warm
- premium
- human
- emotional
- curated
- modern
- editorial
- contemporary Indian craftsmanship
- Gen-Z friendly
- Instagram-worthy

Avoid:
- generic ecommerce templates
- SaaS/dashboard aesthetics
- corporate interfaces
- cheap gifting aesthetics
- overly traditional ethnic styling
- childish UI
- generic AI-generated website styling

## Color system

### Deep Pine
`#14381F`
Primary dark green, strong headings, primary buttons, dark sections.

### Forest
`#285C3A`
Secondary green, supporting UI and accents.

### Muted Moss
`#587A5B`
Subtle supporting accents.

### Soft Sage
`#A8BFA5`
Soft backgrounds and highlight areas.

### Pale Sage
`#DCE6D8`
Very subtle surfaces, tags and accents.

### Warm Ivory
`#FFF8E7`
Dominant light/background canvas.

### Charcoal
`#1C1C1A`
Primary text.

### Removed color
`#CDEDB3` (old Green Tea) is permanently removed. DO NOT USE IT.

## Color balance
Ivory should dominate. Deep/Forest green provides contrast. Moss/Sage support. Pale Sage is subtle. Do not make the entire website green.

## Typography
Use an elegant editorial serif direction for important headlines (Canela/Bodoni Moda-like) and a clean modern sans-serif for body/UI.

Typography should feel refined, spacious and confident.

Avoid cartoon fonts, excessive uppercase, excessive bolding, and too many font styles.

## Layout
Use:
- generous whitespace
- strong alignment
- editorial composition
- intentional asymmetry where useful
- balanced image/text relationships
- controlled content density

Do not cram content.

## Cards
Premium, soft and minimal:
- moderate corner radius
- subtle shadow
- subtle border where useful
- warm ivory/pale sage surfaces
- generous padding

Avoid heavy shadows, glassmorphism, neon gradients, thick borders and dashboard-like density.

## Buttons
Primary: Deep Pine, light text, moderate radius, comfortable padding.
Secondary: light/transparent, Deep Pine border/text.
Avoid excessive pill buttons unless specifically requested.

## Imagery
Warm, tactile, human, natural, editorial and handcrafted.
Prefer customised gifts, handmade products, packaging, personal notes, Indian craft and meaningful gifting moments.
Avoid cheap stock, oversaturation, busy backgrounds and artificial-looking visuals.

## Decorative language
Use subtle organic details only:
- botanical line art
- organic curves
- tiny dots
- hand-drawn details
- soft abstract shapes
- light grain

Decoration must remain secondary.

## Iconography
Use one consistent minimal/refined icon family with thin/medium strokes.

## Responsive design
ONE implementation only. Never make separate desktop/mobile files or component trees.

Use responsive CSS, media queries, grid, flexbox, fluid typography and responsive spacing.

Mobile is a responsive state of the same frontend, not a second frontend.

Test large desktop, desktop, laptop, tablet, large mobile and small mobile.

No horizontal overflow, clipped text, broken grids, overlapping elements or unreadable typography.

## Animation
Keep calm and premium:
- subtle hover
- gentle transitions
- restrained reveals

Avoid bouncing, excessive parallax, aggressive animations and distracting effects.

## Reference images
When a future prompt includes a reference image, use it for composition, hierarchy, spacing, card structure, image/text relationships and responsive principles.

Do NOT blindly copy the reference's brand, content, features, colors or business logic unless explicitly requested.

Translate the reference into Tohfa.

## Final visual standard
Every screen should feel like:
PREMIUM + WARM + EDITORIAL + HUMAN + MODERN INDIAN GIFTING.

When two choices are possible, prefer the simpler, more spacious, intentional and premium option.
